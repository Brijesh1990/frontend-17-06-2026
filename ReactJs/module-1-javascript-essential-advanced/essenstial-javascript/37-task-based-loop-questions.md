## 20 Task-Based Questions on Loops in JavaScript

1. Write a JavaScript program using a for loop to print numbers from 1 to 20.

2. Write a program using a while loop to print all even numbers from 1 to 50.

3. Write a program using a for loop to calculate the sum of numbers from 1 to 100.

4. Write a program using a while loop to calculate the factorial of a given number.

5. Write a program using a loop to print the multiplication table of a given number from 1 to 10.

6. Write a program using a for loop to print all odd numbers between 1 and 100.

7. Write a program using a loop to reverse a given number.
**Example: 12345 → 54321**

8. Write a program using a while loop to count the number of digits in a given number.

9. Write a program using a loop to check whether a given number is a palindrome.
**Example: 121 → Palindrome**

10. Write a program using a loop to find the largest digit in a given number.
Example: 58329 → 9

11. Write a program using a loop to find the smallest digit in a given number.
Example: 58329 → 2

12. Write a program using nested loops to print the following pattern:
```
*
**
***
****
*****
```

13. Write a program using nested loops to print the following pattern:
```
1
12
123
1234
12345
```

14. Write a program using a loop to print the Fibonacci series up to N terms.

**Example: 0 1 1 2 3 5 8 ...**

15. Write a program using a loop to check whether a given number is a prime number.

16. Write a program using a loop to print all prime numbers between 1 and 100.

17. Write a program using a loop to calculate the sum of all digits of a given number.
Example: 12345 → 15

18. Write a program using a loop to find the GCD (Greatest Common Divisor) of two numbers.

19. Write a program using a loop to calculate the power of a number without using Math.pow().
**Example: 2³ → 8**

20. Write a program using nested loops to print the following inverted pattern:
```
*****
****
***
**
*
```
