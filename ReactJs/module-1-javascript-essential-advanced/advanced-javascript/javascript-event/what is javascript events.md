# what is javascript events ?
- events performed some action there we used event in js 
- events are performed some task or action there we used event in js 

# types of events in js ?
- window event
- mouse event
- keyboard event

1. **window event**
  
  - This event load when window or webpages loading
  - This event is always called inside of body tag
  - Event always called when function is called 
  
  **examples**
  
  1. onload 
  2. onunload

2. **mouse event**
  
  - This event load via mouse performed some action
  - This event is called body | button | input etc
  - Event always called when function is called 
  
  **examples**
  
  1. onmouseover 
  2. onmouseout
  3. onchange
  4. onblur
  5. onclick
  6. ondbclick
