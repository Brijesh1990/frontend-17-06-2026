## types of css selector 
 1. element selector (tags)
 2. universal selector (*) 
 3. Id selector  (#)
 4. class selector (.)
 5. combinator selector 
    1. descendent combinator selector (space)
    2. child combinator selector (>)
    3. next sibling selector (+)
    4. subsequent sibling selector (~)
 6. grouping selector  (h1,h2)
 7. pseudo element selector (::after or ::before)
 8. pseudo class selector (a:link , a:active , a:hover , a:visited)
 9. attributes selector   (::placeholder)
