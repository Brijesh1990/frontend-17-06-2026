# What is Bootstrap?

Bootstrap is a popular open-source front-end framework for building responsive, mobile-first websites and web applications. It includes a collection of CSS, JavaScript, and HTML components that help developers create consistent UI layouts quickly.

## Key features

- **Responsive grid system**: A flexible 12-column layout system for building responsive pages.

- **Prebuilt components**: Buttons, navigation bars, cards, forms, modals, alerts, and more.


- **Utility classes**: Simple helper classes for spacing, alignment, colors, display, and more.


- **JavaScript plugins**: Interactive components like dropdowns, carousels, tooltips, and modals.


- **Mobile-first design**: Styles are optimized for small screens first, then scale up for larger devices.

## Why use Bootstrap?

Bootstrap saves time by providing ready-made styles and components, reducing the need to write custom CSS from scratch. It helps maintain visual consistency and supports rapid prototyping.

## How Bootstrap works

1. Include Bootstrap's CSS and JavaScript files in your project.
2. Use Bootstrap classes in your HTML elements to apply styles and layout rules.
3. Use the grid system to arrange page content in rows and columns.
4. Add Bootstrap components and utilities to build a responsive interface quickly.

## Example

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css">

<div class="container">
<div class="row">
<div class="col-md-6">
<h1>Hello, Bootstrap!</h1>
</div>
<div class="col-md-6">
<button class="btn btn-primary">Click me</button>
</div>
</div>
</div>
```

Bootstrap is widely used because it gives developers a solid foundation for building responsive, accessible, and modern web interfaces.
